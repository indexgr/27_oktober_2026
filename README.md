# Gilang & Ayu — Anniversary 2 Tahun

Website anniversary personal untuk Gilang Ramdan dan Ayu Rahmawati.

## Isi project
- `index.html` — halaman website dan surat cinta yang sudah dipersonalisasi
- `style.css` — desain romantis, responsif, dan animasi
- `script.js` — interaksi website dan penghitung hari otomatis
- `README.md` — panduan ini

## Cara menjalankan
1. Ekstrak `anniversary-2-tahun-personal.zip`.
2. Buka foldernya di VS Code.
3. Buka `index.html` dengan ekstensi Live Server, atau klik dua kali untuk membuka di browser.
4. Website tidak memerlukan Node.js, Docker, PHP, atau database.

## Personalisasi yang sudah diterapkan
- Nama: Gilang Ramdan & Ayu Rahmawati
- Tanggal jadian: 27 Oktober 2024
- Panggilan pasangan: Sayang
- Surat cinta khusus untuk Ayu dari Gilang
- Penghitung hari otomatis dari tanggal jadian

## Menambahkan foto kalian
Saat ini galeri memakai placeholder dekoratif. Untuk memasukkan foto:
1. Buat folder `assets` di dalam folder project.
2. Salin foto kalian ke folder `assets`, misalnya `foto-berdua.jpg`.
3. Ganti elemen placeholder yang diinginkan di `index.html` dengan:
   `<img src="assets/foto-berdua.jpg" alt="Gilang dan Ayu">`
4. Tambahkan CSS untuk mengatur foto sesuai layout. Jangan lupa gunakan nama file foto yang benar.

Google Fonts memakai koneksi internet. Website tetap dapat dibuka offline dengan font fallback.
